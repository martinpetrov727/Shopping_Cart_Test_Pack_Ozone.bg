# Ozone.bg – Shopping Cart & Checkout Test Cases

## 📌 Overview
This project contains manual test cases for the shopping cart and checkout functionality of the Ozone.bg e-commerce platform.

The objective is to ensure a smooth and reliable purchasing experience for both guest and registered users.

---

## 🎯 Scope
- Add to cart functionality
- Cart management (quantity, removal)
- Promo codes and coupons
- Checkout process
- Cart persistence behavior

---

## 🧪 Test Coverage
The test cases include:

- ✅ Positive scenarios (successful add to cart and checkout)
- ❌ Negative scenarios (invalid inputs, missing fields)
- 🔢 Quantity validation (invalid, edge values)
- 🎟️ Promo code and coupon validation
- 🛒 Cart persistence (refresh, login, browser restart)
- 💳 Checkout flow validation

---

## 🛠️ Approach
- Manual testing
- Real user behavior simulation
- Validation of UI responses and system logic

---

## 📂 Structure
Each test case includes:
- Test Case ID
- Title
- Preconditions
- Steps
- Expected Result
